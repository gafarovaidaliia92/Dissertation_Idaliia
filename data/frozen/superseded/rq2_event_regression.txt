==============================================================================
RQ2 [C] — H2: does the TYPE of CBDC communication move bank equity?
==============================================================================

  bank-events on file      : 2956
  used in estimation       : 2956   (dropped 0 for missing RHS)
  banks                    : 276
  events                   : 11    distinct values of S : 10  (two events tie at S = 1.00)
  dependent variable       : CAR over [t0-1, t0+5], market-model abnormal returns
  banks with an ML score   : 2946 bank-events (275 banks)

  HOW TO READ THIS REPORT.
  Sections 0-2 are CONTEXT: did the market react on average, and does the
  average reaction line up with the communication type (gamma1 on S)?
  Sections 3-4 are the HEADLINE H2 TEST requested by the supervisor: the
  two-way fixed-effects interaction
      CAR = EventFE + BankFE + b * (S x vulnerability) + e
  run once per vulnerability measure (uninsured_share; leakage-free ML
  score). The interaction isolates the WITHIN-EVENT comparison of vulnerable
  against less-vulnerable banks, which removes the between-event confound
  that Sections 1-2 are exposed to.

  H2 (as written). Communications that emphasise PROTECTIVE design (higher S)
  produce LESS NEGATIVE abnormal returns than expansive ones. In the
  between-event form the prediction is gamma1 > 0 in CAR = gamma0 + gamma1*S;
  in the interaction form it is b > 0 (as S rises, the penalty carried by
  vulnerable banks shrinks).

  STRUCTURAL POINT — READ BEFORE THE TABLES.
  S varies ONLY at the event level: constant within each event, so it
  carries 11 event-level values (10 of them distinct). Therefore:
    (a) NO event-fixed-effects specification is estimated for S. Event
        dummies absorb S perfectly (exact collinearity), so gamma1 would not
        be identified at all — that is a design fact, not a null result.
    (b) SEs are clustered on the EVENT, not on the bank, because the event
        is the level at which the regressor varies. Bank-clustered SEs
        would treat 276 banks as independent information about a
        regressor that takes only 11 values. Event-clustered inference is
        read off t with G-1 = 10 degrees of freedom.
    (c) gamma1 is identified off 11 events and is IMPRECISE BY
        CONSTRUCTION. With 11 clusters the cluster-robust SE is itself a
        small-sample object. Section 1 makes the same comparison honestly,
        with n = 11 in plain sight.

  These three points apply to the S MAIN EFFECT only. They do not block the
  interaction in Sections 3-4: S x vulnerability varies across banks as well
  as across events, so it survives both sets of dummies. Each section
  verifies that numerically before estimating anything.

SECTION 0 — DID THE MARKET REACT AT ALL?  (PRIMARY H2 EVIDENCE)
==============================================================================

  H2 asks whether the type of CBDC communication moves bank equity. The
  first question is therefore unconditional: was there any measurable
  reaction to these 11 dates? If not, there is no average communication
  effect for S to explain, and the S regressions below are testing a
  gradient across events that did not move prices in the first place.

  Source: scripts/rq2_enrich.py, PART B — reproduced verbatim from
  data/processed/rq2_enrichment_results.txt (market model, one factor).
  The relevant test is the Brown-Warner CROSS-CORRELATION-ROBUST portfolio
  test: per-event cross-sectional t-stats treat banks as independent
  within a date, which they are not, and are inflated.

SECTION 3 — H2 AS A TWO-WAY FIXED-EFFECTS INTERACTION
              vulnerability = uninsured_share
==============================================================================

  Model requested by the supervisor:
      CAR = EventFE + BankFE + b * (S x vulnerability) + e
  It isolates the WITHIN-EVENT comparison of vulnerable against
  less-vulnerable banks, so the between-event confound (different macro
  news on different speech dates) is differenced out by the event dummies.

-- orientation and scale of the vulnerability measure --

  uninsured deposits / total deposits, taken from the last Call Report
  quarter ending strictly before t0. Raw fraction on [0, 1]; already
  oriented higher = more vulnerable (more run-prone funding). NOT rescaled.
  Varies across BOTH banks and events: the 11 events draw on 8 distinct
  characteristic quarters.

-- structural checks (numerical, not asserted) --

    regressor on fixed effects                                R^2   max |resid|     resid SD
    ----------------------------------------------------------------------------------------
    S on event dummies                             1.000000000000     1.910e-14    7.153e-15  ABSORBED
    uninsured_share on bank dummies                0.915577267246     3.701e-01    4.248e-02  survives
    uninsured_share on bank + event dummies        0.946024239041     3.556e-01    3.397e-02  survives
    S x vulnerability on bank + event dummies      0.879790143209     4.252e-01    7.224e-02  survives

    Reading:
    * S is absorbed by the event dummies to machine precision. Its main
      effect is therefore NOT estimated under any FE spec. This is exact
      COLLINEARITY, not an effect of zero: S is constant within an event,
      so the S column is a linear combination of the event dummies.
    * The vulnerability measure is NOT absorbed by the bank dummies
      (R^2 = 0.915577, residual SD 4.248e-02). This
      measure is bank-event level, not static: it is re-read from the last
      Call Report quarter before each event, and the 11 events draw on 8
      distinct characteristic quarters. Its main effect therefore REMAINS
      IDENTIFIED under bank FE and is estimated and reported. The
      supervisor's premise that the vulnerability main effect drops out
      holds only for a static measure; it does not hold here, and we
      report the main effect rather than suppress it.
    * The interaction survives both sets of dummies (residual SD 7.224e-02),
      because it varies across banks AND across events. That is what makes
      the two-way FE model estimable at all.

-- D1. CALENDAR PLACEBO: is the interaction about the SIGNAL or about TIME? --

    The 11 events are not randomly ordered in S: later communications are
    more protective. Across the 11 events,
      corr(S, calendar rank) = Pearson +0.60333196 (p 0.049394), Spearman +0.65148233 (p 0.029884)

    regressor. If the coefficient survives only on S and not on time, the
    signal interpretation is supported; if time does the same work, the

    not a response to the safeguard content.

SECTION 4 — H2 AS A TWO-WAY FIXED-EFFECTS INTERACTION
              vulnerability = vulnerability_score (RF, leakage-free)
==============================================================================

  Model requested by the supervisor:
      CAR = EventFE + BankFE + b * (S x vulnerability) + e
  It isolates the WITHIN-EVENT comparison of vulnerable against
  less-vulnerable banks, so the between-event confound (different macro
  news on different speech dates) is differenced out by the event dummies.

-- orientation and scale of the vulnerability measure --

  = -1 x predicted 2023Q1 deposit growth from the RandomForest fitted on the
  688 non-listed wide-population banks and applied to the listed banks
  (vulnerability_scores_wide.csv). Already oriented higher = more
  vulnerable, because a predicted OUTFLOW (negative growth) maps to a
  positive score. NOT rescaled. STATIC 2022Q4 profile: one value per bank,
  constant across all 11 events.

    Reading:
    * S is absorbed by the event dummies to machine precision. Its main
      effect is therefore NOT estimated under any FE spec. This is exact
      COLLINEARITY, not an effect of zero: S is constant within an event,
      so the S column is a linear combination of the event dummies.
    * The vulnerability measure is STATIC (one value per bank), so it is
      absorbed by the bank dummies to machine precision as well. In the
      two-way FE model ONLY the interaction b is identified, and only b
      is reported there.
    * The interaction survives both sets of dummies (residual SD 6.898e-03),
      because it varies across banks AND across events. That is what makes
      the two-way FE model estimable at all.

-- D1. CALENDAR PLACEBO: is the interaction about the SIGNAL or about TIME? --

    The 11 events are not randomly ordered in S: later communications are
    more protective. Across the 11 events,
      corr(S, calendar rank) = Pearson +0.60333196 (p 0.049394), Spearman +0.65148233 (p 0.029884)

    So 'S x vulnerability' and 'time x vulnerability' are close to the same
    regressor. If the coefficient survives only on S and not on time, the
    signal interpretation is supported; if time does the same work, the
    interaction is a trend in how vulnerable banks priced over 2019-2023,
    not a response to the safeguard content.

    Both interactions are built from z-scored S and z-scored calendar rank,
    so the two coefficients are directly comparable.

    events, so the joint model has little power to separate them; read it
    as a warning flag, not as a clean decomposition.

-- verdict for this measure --

    b (two-way FE) = -0.38507629   p = 0.022081 (two-way SE), 0.011488 (event SE)
    H2 predicts b > 0. Observed sign: NEGATIVE (AGAINST H2).
    'b is null under event / two-way FE': DOES NOT HOLD  (event-FE p = 0.017262 two-way SE)

    b IS DISTINGUISHABLE FROM ZERO, AND ITS SIGN IS THE OPPOSITE OF
    WHAT H2 PREDICTS. Before this is read as evidence against H2, three
    things from the diagnostics above have to travel with it:
      D1 calendar placebo. corr(S, calendar rank) = +0.603332
         (p 0.049394). Interacted with time instead of S the
         coefficient is -0.17749331 (p 0.088629) — same sign,
         similar size. Entered jointly, NEITHER survives (S p 0.209590,
         time p 0.468709). With 11 events the design cannot
         separate 'more protective communication' from 'later in the
         sample', and the 2022 rate cycle sits inside that window.
      D2 leave-one-event-out: b ranges [-0.52063335, -0.30804490]
         and never flips sign, so it is not one event driving it.
      D3 dropping the 9 trust/custody banks moves b to -0.13939961
         (p 0.063319) — 63.8% of the magnitude comes from
         custodians, whose rate exposure is a competing explanation.

    Honest reading: a within-event pattern IS present, but it cannot be
    attributed to the safeguard content rather than to the calendar or
    to custodian bank type. It is not support for H2 either way — the
    sign is wrong for H2.

    HOW TIGHT IS THIS NULL. MDE at 80% power for gamma1 (pooled, with
    controls, event-clustered) = 0.0479 per unit of S, i.e. 2.37 pp of
    CAR per one-SD move in S — about 49% of a CAR standard deviation (4.81 pp).
    That is a WIDE bound, and it should be stated as one: with 11 events the
    design can rule out a large average communication effect but not a modest
    one. Contrast the H3 coefficient, whose MDE is ~5% of a CAR SD
    (rq2_enrichment_results.txt, PART C). H2's null is directionally clear but
    not tightly bounded.

    H2 predicts gamma1 > 0. Observed sign: POSITIVE (H2 direction) at the event level, POSITIVE pooled with controls.  Significant at 5%: NO.

    Read together with Section 0: the unconditional test finds no event with
    a mean CAR distinguishable from zero. A null gamma1 is therefore not a
    surprise — there is no average price reaction for the communication type
    to modulate.
