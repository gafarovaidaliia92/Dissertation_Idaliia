RQ2 [C] — CBDC safeguard signal x uninsured-deposit exposure and bank CARs
==============================================================================

  bank-events on file      : 2956
  used in estimation       : 2956   (dropped 0 for missing RHS)
  banks (SE clusters)      : 276
  events                   : 11
  dependent variable       : CAR over [t0-1, t0+5], market-model abnormal returns
  primary interaction      : S (safeguard score) x uninsured_share

  READING NOTE. With only 11 events, S has 11 distinct values, so beta1
  (S alone) is estimated off 11 points and is imprecise by construction —
  it should not be read as an event-level effect. beta3 = S:uninsured_share
  is the identified coefficient of interest: it uses within-event
  cross-sectional variation in uninsured exposure, which is exactly what
  the event-FE spec isolates.

  H2 direction: a weaker safeguard signal (low/negative S) should hurt
  uninsured-heavy banks more, i.e. beta3 > 0 (as S rises, the penalty on
  uninsured_share shrinks).
