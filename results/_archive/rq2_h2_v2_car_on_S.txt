==============================================================================
RQ2 [C] — H2: does the TYPE of CBDC communication move bank equity?
==============================================================================

  bank-events on file      : 2956
  used in estimation       : 2956   (dropped 0 for missing RHS)
  banks                    : 276
  events                   : 11    distinct values of S : 10  (two events tie at S = 1.00)
  dependent variable       : CAR over [t0-1, t0+5], market-model abnormal returns
  coefficient of interest  : gamma1 on S (safeguard score)

  H2 (as written). Communications that emphasise PROTECTIVE design (higher S)
  produce LESS NEGATIVE abnormal returns than expansive ones. This is a
  statement about the average effect of the communication, so the
  prediction is gamma1 > 0 in  CAR = gamma0 + gamma1*S + controls.

  STRUCTURAL POINT — READ BEFORE THE TABLES.
  S varies ONLY at the event level: constant within each event, so it
  carries 11 event-level values (10 of them distinct). Therefore:
    (a) NO event-fixed-effects specification is estimated for S. Event
        dummies absorb S perfectly (exact collinearity), so gamma1 would not
        be identified at all — that is a design fact, not a null result.
    (b) SEs are clustered on the EVENT, not on the bank, because the event
        is the level at which the regressor varies. Bank-clustered SEs
        would treat 276 banks as independent information about a
        regressor that takes only 11 values. Event-clustered inference is
        read off t with G-1 = 10 degrees of freedom.
    (c) gamma1 is identified off 11 events and is IMPRECISE BY
        CONSTRUCTION. With 11 clusters the cluster-robust SE is itself a
        small-sample object. Section 1 makes the same comparison honestly,
        with n = 11 in plain sight.

  What is NOT the H2 test: the S x uninsured_share interaction. That asks
  whether exposed banks react differently WITHIN an event — a
  cross-sectional question, closer to H3 in spirit. It is retained in
  Section 3 as a robustness/extension, clearly labelled.

==============================================================================
SECTION 0 — DID THE MARKET REACT AT ALL?  (PRIMARY H2 EVIDENCE)
==============================================================================

  H2 asks whether the type of CBDC communication moves bank equity. The
  first question is therefore unconditional: was there any measurable
  reaction to these 11 dates? If not, there is no average communication
  effect for S to explain, and the S regressions below are testing a
  gradient across events that did not move prices in the first place.

  Source: scripts/rq2_enrich.py, PART B — reproduced verbatim from
  data/processed/rq2_enrichment_results.txt (market model, one factor).
  The relevant test is the Brown-Warner CROSS-CORRELATION-ROBUST portfolio
  test: per-event cross-sectional t-stats treat banks as independent
  within a date, which they are not, and are inflated.

-- B1c. Cross-correlation-robust portfolio test --

    The per-event t-stats in B1 assume banks are independent within a
    date. They are not: a common factor moves them together, so those
    t-stats are inflated, often by an order of magnitude. This test uses
    the equal-weighted portfolio AR and its own estimation-window
    time-series SD, which is robust to that dependence.

SECTION 1 — H2 AT THE EVENT LEVEL  (the honest form of the test, n = 11)
==============================================================================

  S is a property of the COMMUNICATION, not of the bank: it is constant
  within an event, so it carries 11 event-level values. H2 is therefore a
  between-event question, and the natural test has 11 observations: does a
  more protective communication (higher S) come with a less negative
  average abnormal return? H2 predicts gamma1 > 0.

==============================================================================
SPEC 3 — EVENT FIXED EFFECTS: NOT ESTIMABLE FOR S
==============================================================================
  CAR ~ S + controls + C(doc_id) is not reported because C(doc_id) absorbs S
  exactly: S is constant within each of the 11 events, so the S column is a
  linear combination of the event dummies. Any software that returns a
  number here is reporting an artefact of its pseudo-inverse, not an
  estimate. The between-event variation that identifies H2 is precisely what
  event FE removes.

==============================================================================
SECTION 3 — ROBUSTNESS / EXTENSION: S x uninsured_share  (NOT the H2 test)
==============================================================================

  This section answers a DIFFERENT question from H2: within a given event,
  do banks with more uninsured deposits react differently? That is a
  cross-sectional exposure question and sits closer to H3 (CAR ~
  vulnerability_score) than to H2. beta3 = S:uninsured_share is its
  coefficient; it is reported here for completeness and because the
  interaction was the specification used in an earlier version of this
  analysis (preserved at rq2_event_regression_interaction.txt).

  Because uninsured_share varies within events, event FE IS legitimate here
  and is the identifying specification for beta3. SEs are clustered on the
  bank in this section, matching the level of the varying regressor.

SUMMARY — H2
==============================================================================

    test                                             estimate          SE         p
    --------------------------------------------------------------------------------
    event level: gamma1, mean_CAR ~ S (n=11)         0.005629    0.018874    0.7723
    pooled: gamma1, no controls (cl=event)           0.006177    0.017194    0.7269
    pooled: gamma1, with controls (cl=event)         0.006441    0.017113    0.7145
    Pearson corr(event-mean CAR, S)                    0.0989                0.7723
    Spearman corr(event-mean CAR, S)                   0.0137                0.9682
    mean CAR: protective - expansive                 -0.00561

    HOW TIGHT IS THIS NULL. MDE at 80% power for gamma1 (pooled, with
    controls, event-clustered) = 0.0479 per unit of S, i.e. 2.37 pp of
    CAR per one-SD move in S — about 49% of a CAR standard deviation (4.81 pp).
    That is a WIDE bound, and it should be stated as one: with 11 events the
    design can rule out a large average communication effect but not a modest
    one. Contrast the H3 coefficient, whose MDE is ~5% of a CAR SD
    (rq2_enrichment_results.txt, PART C). H2's null is directionally clear but
    not tightly bounded.

    H2 predicts gamma1 > 0. Observed sign: POSITIVE (H2 direction) at the event level, POSITIVE pooled with controls.  Significant at 5%: NO.

    Read together with Section 0: the unconditional test finds no event with
    a mean CAR distinguishable from zero. A null gamma1 is therefore not a
    surprise — there is no average price reaction for the communication type
    to modulate.
